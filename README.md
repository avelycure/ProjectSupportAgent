# Project Support Agent

Локальный сервис поддержки продуктов с CRM на JSON, MCP-интерфейсом и лендингом с чатом. Агент ищет подходящие фрагменты Markdown-документации (RAG), получает сведения выбранного тикета через MCP и формирует ответ через OpenAI-совместимую облачную модель. Код не привязан к Invest Manager: каждый продукт описывается отдельной папкой `projects/<id>/`.

> Демо-проект Invest Manager содержит **вымышленные** тикеты и пользователя. Это пример интеграции, а не доступ к личному Obsidian-хранилищу.

## Быстрый запуск

Нужен Node.js 22 или новее.

```bash
npm install
cp .env.example .env
# Укажите CLOUD_API_KEY, CLOUD_BASE_URL и CLOUD_MODEL в .env
npm start
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Сервис слушает только loopback-адрес `127.0.0.1` по умолчанию. В `.env.example` установлен OpenAI-совместимый API; можно указать другого совместимого провайдера. Секреты не попадают в браузер и исключены из Git.

Без ключа чат доступен в режиме выдержек: он ищет подходящие разделы документации и показывает их с источниками, но не генерирует связный ответ моделью. Для полноценного ответа нужен ключ облачной модели. Локальная LLM не используется.

## Что работает

- Лендинг объясняет поток документация → MCP CRM → ответ и содержит интерактивный чат.
- Выбор проекта и тикета. При выбранном тикете сервер через MCP получает его историю и пользователя.
- Локальный поиск BM25 по Markdown-файлам проекта. В облако отправляются только найденные фрагменты, вопрос и контекст выбранного тикета при настроенном ключе.
- MCP-сервер с инструментами `list_projects`, `get_project`, `list_tickets`, `get_ticket`, `get_user`. Все инструменты только для чтения.
- История трёх предыдущих обменов поддерживает уточняющие вопросы в пределах текущей страницы.

## Подключить другой продукт

Скопируйте `projects/invest-manager` в `projects/<новый-id>`, измените `project.json`, положите Markdown-документы в `docs/` и подготовьте `data/users.json` и `data/tickets.json`. Подробный формат — в [docs/project-format.md](docs/project-format.md). Перезапуск приложения нужен для новой конфигурации окружения; документы и JSON перечитываются при запросах.

## MCP отдельно от веб-страницы

```bash
npm run mcp
```

Это stdio MCP-сервер для клиентов, умеющих запускать локальные команды. Веб-приложение само запускает отдельный процесс MCP и вызывает его инструменты; MCP здесь не имитация. Пример конфигурации и список инструментов — в [docs/mcp.md](docs/mcp.md).
