# Демо для задания «Ассистент поддержки пользователей»

1. Запустите `npm start` и откройте <http://127.0.0.1:4173>.
2. Покажите раздел «Как работает»: Markdown-документация используется для RAG, JSON CRM доступна через MCP.
3. В демо выберите тикет `IM-101` и спросите «Почему не работает вход в Telegram?». Ответ должен учитывать сообщение о превышении попыток и ссылаться на `faq.md` или `troubleshooting.md`.
4. Выберите «Без тикета» и спросите «Как добавить новый проект?». Ответ должен использовать `agent/project-format.md`.
5. Покажите `docs/mcp.md` и команду `npm run mcp`: это реальный stdio MCP-сервер с инструментами чтения.
6. Покажите `.env.example` без настоящего ключа. Если ключ не настроен, чат честно показывает выдержки из документов; для генерации ответа укажите ключ в локальном `.env`.

В демонстрационном JSON нет реальных пользователей или секретов. В репозитории нет видеозаписи; этот сценарий можно использовать для её создания.
