# MCP CRM

Локальный MCP-сервер работает по stdio:

```bash
npm run mcp
```

Пример настройки клиента:

```json
{
  "mcpServers": {
    "project-support-crm": {
      "command": "node",
      "args": ["/absolute/path/to/ProjectSupportAgent/src/mcp-server.js"]
    }
  }
}
```

| Инструмент | Назначение |
| --- | --- |
| `list_projects`, `get_project` | Проекты и метаданные |
| `get_session`, `add_agent_exchange` | История разговора посетителя |
| `create_ticket`, `add_user_message` | Передача оператору и последующие сообщения посетителя |
| `list_tickets`, `get_ticket` | Очередь и полная история для менеджера |
| `reply_ticket`, `close_ticket` | Ответ менеджера и закрытие обращения |

Веб-сервер вызывает MCP через локальный дочерний процесс. Публичный HTTP API не предоставляет список тикетов, чтение чужого обращения или менеджерские операции. Отдельный stdio-клиент MCP имеет доступ к локальным данным и предназначен для доверенной среды; не публикуйте его удалённо без собственной аутентификации.
