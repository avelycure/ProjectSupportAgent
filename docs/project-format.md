# Формат проекта

## Как добавить новый проект

Создайте папку `projects/<id>/` с `project.json` и Markdown-документами в `docs/`. Пользователей и тикеты вручную создавать не требуется: обращения появятся в локальном `var/<id>.json`, когда посетитель попросит оператора.

```text
projects/my-product/
  project.json
  docs/overview.md
  docs/faq.md
  docs/troubleshooting.md
```

ID содержит строчные латинские буквы, цифры и дефис, до 64 символов. Пример `project.json`:

```json
{
  "id": "my-product",
  "name": "My Product",
  "description": "Краткое описание продукта",
  "productUrl": "https://example.com",
  "language": "ru"
}
```

Все `.md` файлы непосредственно в `docs/` участвуют в поиске. Добавляйте проверенные FAQ, инструкции, функции и типовые ошибки. Общая документация самого агента из корневого `docs/` также доступна для вопросов об этом сервисе.
