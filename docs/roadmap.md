# План развития

1. Аутентификация посетителей и менеджеров с ролями для работы вне одного компьютера.
2. Уведомления менеджеру о новых обращениях и посетителю об ответе.
3. Импорт документации из репозитория продукта с указанием версии.
4. Необязательные облачные эмбеддинги для больших баз знаний; сейчас используется локальный BM25.
5. Ссылки на конкретные разделы документации и оценки качества ответов.
6. Адаптеры внешних CRM через MCP после настройки прав доступа.
