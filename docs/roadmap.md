# План развития

1. Добавить управляемый импорт документации из репозитория продукта с указанием версии, чтобы демонстрационная база знаний не устаревала.
2. Добавить облачные эмбеддинги как необязательный режим семантического поиска для больших баз знаний; текущий BM25 остаётся локальным базовым режимом.
3. Ввести подтверждённые ссылки на конкретные разделы документации, а не только имена файлов.
4. Добавить адаптеры к реальным CRM через MCP после настройки авторизации, ролей и политики хранения.
5. Добавить оценки ответа и сценарии проверки качества на обезличенных тикетах.

Эти пункты не реализованы в текущем прототипе.
