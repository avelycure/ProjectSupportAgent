# Безопасность и приватность

- Веб-сервер по умолчанию слушает только `127.0.0.1`; не ставьте `HOST=0.0.0.0` с реальными данными без аутентификации и TLS.
- Ключ облачной модели хранится в локальном `.env` и не возвращается браузеру. `.env` исключён из Git.
- Поиск по документации и чтение JSON происходят локально. При настроенной облачной модели в запрос входят вопрос, до четырёх найденных разделов, выбранный тикет, связанный пользователь и до трёх прошлых обменов. Не добавляйте в эти поля секреты и данные, на передачу которых нет разрешения.
- Папки проектов выбираются только по безопасному ID. Статические файлы обслуживаются по фиксированному списку путей. В браузере ответы выводятся как текст, без исполнения HTML модели.
- MCP-инструменты только читают данные. Нет записи в CRM, отправки сообщений, работы с Obsidian-хранилищем или автоматического доступа к внешним аккаунтам.
- Демонстрационные пользователи и тикеты вымышлены. Для реальной поддержки нужна модель прав доступа, согласие на обработку данных и политика хранения тикетов.
