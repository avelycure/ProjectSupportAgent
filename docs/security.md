# Безопасность и приватность

- Сервер по умолчанию слушает только `127.0.0.1`. Эта версия предназначена для локальной работы, а не для публикации в интернете.
- Ключ облачной модели и пароль менеджера находятся в локальном `secrets/.env`, который исключён из Git. Они не возвращаются браузеру.
- Админка требует `ADMIN_PASSWORD`. Менеджерская сессия ограничена по времени и хранится в HttpOnly-cookie с `SameSite=Strict`. Публичное API не даёт перечислять или открывать тикеты.
- Посетительская история привязана к случайному HttpOnly-cookie. Это идентификатор сессии, не проверка личности; на общем компьютере данные доступны в том же профиле браузера.
- История и тикеты находятся в локальном `var/`, исключённом из Git. Запись JSON выполняется атомарно, файлы создаются с правами только для владельца.
- В облако передаются вопрос, найденные фрагменты документации и недавние сообщения чата. После передачи оператору новые сообщения не отправляются модели.
- Ответы модели и сообщения пользователей выводятся как текст, без исполнения HTML. Для изменяющих запросов проверяется Origin; статические файлы выдаются по фиксированному списку.
- Отдельный MCP stdio-процесс доверенный и имеет доступ к данным CRM. Не открывайте его наружу без аутентификации и разграничения прав.

Для реальной многопользовательской поддержки потребуются аутентификация посетителей, TLS, разграничение менеджеров, политика удаления данных и аудит доступа.
