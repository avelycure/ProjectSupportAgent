# Сценарий обращения

1. Посетитель открывает <http://127.0.0.1:4173/>, выбирает продукт и задаёт вопрос в чате.
2. Помощник отвечает по документации. Обращение в CRM пока не создаётся.
3. Если нужна помощь человека, посетитель пишет «позови агента» или близкую по смыслу просьбу. Чат показывает номер обращения.
4. Менеджер открывает <http://127.0.0.1:4173/admin> и входит с `ADMIN_PASSWORD` из локального `secrets/.env`.
5. В обращении видна история беседы. Менеджер отвечает, и сообщение появляется в чате посетителя.
6. Менеджер закрывает тикет. После этого посетитель снова может задавать вопросы помощнику.

Тикеты создаются через локальный MCP-сервер и хранятся вне Git.
