# Частые вопросы

## Почему не работает вход в Telegram?

Для MTProto нужны API ID и API hash приложения, созданного на my.telegram.org, а затем вход от имени обычного Telegram-аккаунта по номеру и коду. ID и hash сами по себе не являются сессией пользователя и не дают доступ к подпискам. Если Telegram сообщает о превышении числа попыток, это ограничение Telegram; не запрашивайте код многократно, дождитесь снятия ограничения. Точное время снятия лимита зависит от Telegram и не определяется плагином.

## Почему RSS открывается в браузере, но отчёт предупреждает о неполном охвате?

Доступность URL подтверждает, что лента отвечает, но не означает, что она содержит все публикации за 24 часа. Многие издания ограничивают число записей в выдаче. Invest Manager может использовать локальную историю ленты, если она накоплена, и помечает неполный охват. Проверьте прямой URL RSS/Atom, время публикации и число записей.

## Почему нет ссылок на мои заметки?

Точные совпадения по названию и алиасам доступны без RAG. Для смыслового поиска нужен включённый AskMyMind с построенным индексом и включённый переключатель RAG в Invest Manager. При облачной модели отдельное разрешение управляет передачей фрагментов заметок провайдеру. Ссылки добавляются только при достаточно сильном совпадении и существовании файла.

## Где открыть последнюю сводку?

Во вкладке Invest Manager рядом с кнопкой запуска есть «Открыть последний отчёт». Отчёт сохраняется в настроенной папке статистики по году, месяцу и дню.
