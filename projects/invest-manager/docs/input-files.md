# Входные файлы Invest Manager

Компании портфеля указываются в Markdown-таблице. Обязательны название и тикер Московской биржи. Дополнительное поле «Пресс центр компании» содержит адрес страницы новостей или RSS/Atom-ленты компании.

Темы новостей можно указать списком или таблицей с русскими и английскими вариантами формулировок. Публичные Telegram-каналы можно перечислить через `@username`. Для изданий нужны прямые URL RSS/Atom-лент, а не главные страницы сайтов.

Во вкладке плагина команда `/formats` показывает точные шаблоны и кнопки копирования. Изменение входных файлов не происходит через чат поддержки.
