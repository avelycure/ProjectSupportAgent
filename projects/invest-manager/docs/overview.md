# Invest Manager: что делает продукт

Invest Manager — настольный плагин Obsidian. Он формирует ежедневную инвестиционную сводку: новости по выбранным темам и компаниям портфеля, публикации доступных Telegram-каналов, рыночные показатели, графики и ссылки на подходящие заметки.

В настройках указываются Markdown-файлы компаний, тем, Telegram-каналов и RSS-лент изданий. Готовый отчёт сохраняется в папке `Статистика/год/месяц/день` и показывается во вкладке плагина. Сводку можно запустить кнопкой или запланировать к московскому времени; компьютер должен быть включён для работы плагина.

Кнопка «Помощь» открывает чат по документации. Команды `/help`, `/telegram` и `/formats` показывают встроенные инструкции без вызова модели. Произвольные вопросы требуют настроенной локальной или облачной модели.

Источник: [README Invest Manager](https://github.com/avelycure/InvestManager#readme).
