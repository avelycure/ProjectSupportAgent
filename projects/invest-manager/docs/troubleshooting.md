# Диагностика

## Telegram: слишком много попыток

Проверьте, что номер введён в международном формате, а API ID и API hash относятся к одному приложению. Не повторяйте запрос кода при действующем ограничении Telegram. После паузы выполните вход повторно и нажмите «Проверить MTProto». Не передавайте коды входа или API hash в тикете.

## Новости: неполный интервал

Сначала проверьте, что ссылка ведёт непосредственно на XML RSS/Atom. Затем сравните даты самой ранней и самой новой записи с периодом отчёта. Если лента короткая, накопление локального кэша улучшает охват, но прошлые публикации нельзя восстановить из текущей короткой выдачи.

## RAG: заметки не найдены

Проверьте, что AskMyMind включён, индекс построен и доступна модель эмбеддингов. Затем проверьте переключатель RAG в Invest Manager. Если используется облачная модель, отдельное разрешение требуется для отправки фрагментов заметок провайдеру.
