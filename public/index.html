Один агент для разных проектов. Он отвечает по документации с указанием источников и передаёт разговор оператору, когда пользователь просит об этом.

01 / ПРИНЦИП РАБОТЫ

От вопроса до ответа —
без догадок.

Агент отвечает сам, пока пользователь не попросит подключить человека.

01
▤

Ищет в документации

Разбивает Markdown по разделам и отбирает подходящие фрагменты локальным поиском BM25. Проект можно сменить одним выбором.

02
⌘

Передаёт оператору

По просьбе пользователя создаёт тикет через MCP. Менеджер видит историю беседы в отдельной админке.

03
✳

Даёт проверяемый ответ

Облачная модель получает найденные фрагменты и недавние сообщения чата. Ответ показывает файлы-источники и отделяет факты от предположений.

02 / АРХИТЕКТУРА

Один движок.
Разные продукты.

Каждый проект — отдельная папка с описанием и документацией. Обращения хранятся локально и видны менеджерам в админке.

✓

Демо-проект: Invest Manager
Документация о Telegram, RSS и связанных заметках. Можно задать вопрос или передать беседу оператору.

● ● ●projects/<project-id>/
project.json          # имя и описание
docs/
  faq.md              # ответы на вопросы
  overview.md         # описание продукта
  troubleshooting.md  # диагностика

var/                  # локальные обращения
MCP tools: create_ticket · list_tickets · get_ticket · reply_ticket
